## Overview
A Python prototype that plans multi-trip parcel deliveries across a weighted road network by combining:
- **Merge Sort** to prioritize parcels by earliest deadline, higher priority, and parcel ID (benchmarked against Quick Sort, Insertion Sort, and Python's built-in `sorted()`).
- **0/1 Knapsack (Dynamic Programming)** to pick the highest-value parcel load within the van's weight capacity on each trip.
- **Dijkstra's Algorithm (Binary Heap)** to compute shortest road paths between locations.
- **Nearest-Neighbour TSP Heuristic** to order stops on each trip and return to the depot.

## Setup & Execution
1. Ensure **Python 3.9+** is installed.
2. Install `matplotlib` (optional, only required for generating benchmark charts):
   ```bash
   pip install matplotlib
   ```
3. Run the program:
   ```bash
   python mini_courier_planner.py
   ```

## Menu Options
- `1` — Run on the **Small Dataset** (10 parcels, 8 nodes, 20 kg capacity)
- `2` — Run on the **Medium Dataset** (60 parcels, 25 nodes, 50 kg capacity)
- `3` — Run on the **Large Dataset** (500 parcels, 100 nodes, 50 kg capacity; shows first 3 trips)
- `4` — Load **Custom CSV** files (press Enter at prompts to use `sample_data/parcels.csv`, `sample_data/graph.csv`, capacity `20`, depot `Depot`)
- `5` — Run **Benchmarks & Graphs** (saves `outputs/runtime_charts.png`)
- `6` — Run **Correctness Tests** (sorting, knapsack vs. brute force, Dijkstra, and edge cases)
- `0` — Exit

*Note: Generated datasets use fixed random seeds so results are repeatable across runs; absolute benchmark timings vary by machine.*
